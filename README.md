Программа осуществляет решение системы линейных уравнений вида Ax = b методом Жордана с выбором главного элемента по строке. Квадратная матрица A считывается из файла произвольного имени или реализуется с помощью одной из четырех формул общего элемента матрицы по образцу из файла "matrix_16.c". В нем же содержатся алгоритмы вычисления норм невязки и погрешности. Непосредственный алгоритм решения содержится в файле "jordan.c". Начиная с первой строки, находится максимальный по модулю элемент с точностью до 1e-14 (данное значение влияет на количество решаемых матриц), который при необходимости переставляется на диагональ, нормируется ведущая строка (главный элемент становится равным 1) и последовательно обнуляются все элементы столбца с тем же номером, что и у ведущей строки. После этого алгоритм переходит к следующей строке.

Исходный код содержится в файле "main_16.c" на языке C. Makefile позволяет собрать программу с элементами отладки (команда make) и без них (команда make debug). Оптимизатор -O2. Можно очистить предыдущий запуск (команда make clean). Исполняемым файлом является "main", который выводит указанное количество строк исходной матрицы, значения норм и время работы, а также проверяет корректность ввода. В файлах с расширением ".h" содержатся объявления необходимых функций, указанных в вспомогательных файлах с расширением ".c".
